# Turning Reading into Questions

## 中文版笔记

## 学习目标

- 区分作者的观点、提供的证据与自己的解释。
- 为一段阅读材料写出可继续探索的问题。

## 关键概念

**观点**是作者希望读者接受的判断。**证据**是用于支持判断的观察、资料或推理。**疑问**指出目前还需要澄清的内容。

> 公开示例：以下短文为演示 YYNotes 的阅读、语言切换与批注功能而编写，并非引用真实研究。

## 主要内容

### 从一段短文开始

阅读材料：“小组讨论时，让每个人先写下自己的想法，再依次分享，可以让更多观点被看见。”

先用自己的话复述：这段文字建议在讨论前安排独立思考。随后分开记录它主张什么，以及它尚未证明什么。

| 阅读层次 | 对这段文字的记录 |
| --- | --- |
| 作者主张 | 先独立记录，再交流 |
| 预期结果 | 更多观点被看见 |
| 尚缺的证据 | 哪些小组、什么任务、与什么方式比较 |
| 可以追问 | 独立记录多久合适？分享顺序是否影响结果？ |

### 留下自己的问题

一个有用的问题可以明确到具体条件：“在十分钟的小组讨论中，先写两分钟想法，是否比直接讨论更容易让每个人参与？”

这仍然是待探索的问题，而不是已经得到验证的结论。阅读笔记可以保留这种区别，避免把推测写成事实。

## 小结

把复述、证据和疑问分开记录。笔记不必替你消除所有疑问；它也可以保存下一步思考的入口。

## English Version

## Learning Objectives

- Distinguish an author's claim, supporting evidence, and your own interpretation.
- Write questions that help you explore a passage further.

## Key Concepts

A **claim** is a judgment the author wants the reader to accept. **Evidence** consists of observations, material, or reasoning supporting that judgment. A **question** identifies what remains unclear.

> Public example: the passage below was written to demonstrate YYNotes reading, language switching, and annotation. It does not quote an actual study.

## Main Content

### Start with a Short Passage

Passage: “During a group discussion, asking everyone to write down their ideas before sharing them in turn can make more perspectives visible.”

Restate it in your own words: the passage recommends independent thinking before discussion. Then record what it claims separately from what it has not yet established.

| Reading layer | Record for this passage |
| --- | --- |
| Author's claim | Write independently, then share |
| Expected outcome | More perspectives become visible |
| Missing evidence | Which groups, which tasks, and which comparison method |
| Questions to pursue | How long should writing take? Does sharing order affect the outcome? |

### Keep Your Own Questions

A useful question can name specific conditions: “In a ten-minute group discussion, does writing ideas for two minutes first make participation easier for everyone than discussing immediately?”

This is a question to explore, not a verified conclusion. A reading note can preserve that distinction and avoid presenting speculation as fact.

## Summary

Record restatement, evidence, and questions separately. A note does not need to eliminate every uncertainty; it can preserve a starting point for further thinking.
